Client Query Management System

A web-based Client Query Management System built using Python, Streamlit, and MySQL.
This project allows clients to submit queries and enables the support team to track, manage, and close them efficiently in real time.

🚀 Features

🔐 Login System (Client & Support roles)

🔒 Secure Password Hashing (SHA-256)

🧑‍💼 Client Dashboard

Submit new queries

Automatic query timestamp

🧑‍🔧 Support Dashboard

View all queries

Close queries with resolution time

🗄️ MySQL Database Integration

📊 Real-time UI using Streamlit

🛠️ Tech Stack

Language: Python

Frontend: Streamlit

Database: MySQL

Libraries:

mysql-connector-python

pandas

datetime
